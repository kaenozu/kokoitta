# こいったのマネタイズ導線

## 決定

写真追加と地図閲覧を無料のまま維持し、ホーム画面の地図・旅行一覧の主操作を覆わない位置に AdMob バナーを表示する。広告が読み込めない場合は広告枠を表示せず、コア機能は継続する。写真追加・地図タップを広告視聴や課金でブロックしない。

## 検証レイヤー

- **実装**: `lib/monetization/ad_banner.dart` が公開テスト広告 ID のみを使い、読み込み前・失敗時は何も表示せず、破棄時に広告を解放する。SDK初期化は起動をブロックしない。
- **Play設定**: `AndroidManifest.xml` の App ID は Google 公開テスト ID。Play Console の広告表示申告、プライバシーポリシー URL、データセーフティ、AdMob 本番アプリ/広告ユニット、支払い設定は未実施の外部ゲートであり、本番収益の証拠ではない。
- **実機 runtime**: 実機での広告ロード・オフライン fallback・同意文言の最終表示は署名済みビルドで別途確認する。ローカル widget test は SDK/network/runtime の代替ではない。

## プライバシー・同意

`AdRequest(nonPersonalizedAds: true)` を使用し、写真・位置情報を広告リクエストへ渡さない。画面上で広告の目的と無料利用への関係を説明する。地域の同意要件（例: EEA/UK の UMP 同意フロー）は本番 AdMob 設定と合わせて実施し、同意取得前にパーソナライズ広告を有効化しない。実 ID・秘密値はリポジトリへ保存しない。

## 本番移行と fallback

本番 ID は安全なリリース設定でのみ差し替え、署名済み内部テストで広告表示、収益イベント、同意状態、オフライン利用を確認する。SDK初期化・広告リクエスト・表示が失敗しても、写真追加、地図、保存済みデータの読み込みを中断しない。
