# オフライン日本地図のデータと設計

## 採用方式

地図タブの日本地図は、外部の地理データ、地図タイル、Web APIを読み込まず、リポジトリ内のDartコードに定義した47都道府県の地理配置型カートグラムとして描画します。

- 安定識別子: JIS都道府県コード相当の `01`〜`47`
- 表示対象: 47都道府県
- 状態: `visited` / `transit` / `unvisited`
- 通信: 不要
- APIキー: 不要
- 外部アセット: なし
- 実行時パース: なし

北海道と沖縄県は、小型Android端末でも見切れず操作できるように拡大・インセット配置しています。都道府県の正確な面積や形状を表す測量用地図ではなく、訪問状態を比較しやすくする情報可視化です。

## ライセンス

地図配置および描画コードは本リポジトリで新規作成したもので、国土地理院、国土数値情報、Natural Earth、OpenStreetMap、Wikimedia Commons等の地理データやSVGを成果物へ取り込んでいません。そのため、地図アセットに関する追加の出典表示・再配布条件はありません。

## フォールバック

地図描画の下には既存の47都道府県ActionChip一覧を維持します。画面制約やアクセシビリティ上の理由で地図操作が難しい場合も、同じ保存データを一覧から更新できます。

## 検証項目

- 01〜47の識別子が重複なく表示される
- 北海道・東京都・沖縄県を地図から操作できる
- 状態を色だけでなくアイコン、凡例、semantic labelで区別できる
- 小型Android相当幅およびダークテーマで例外なく表示される
- 地図タップによる変更が保存され、再起動後も維持される
